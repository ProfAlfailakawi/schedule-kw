# المرشد

سؤال واحد، جواب قصير، و«أرني». كل شيء يعمل في المتصفح بلا خادم ذكاء ولا تكلفة تشغيل.

| الجزء | الملف |
|---|---|
| السجل والصلاحيات (`canAccessGuideFeature`) | `src/guide/smartGuide.ts` |
| بنك المعرفة: خطوات وصيغ أسئلة لكل ميزة | `src/guide/bank.ts` |
| التطبيع والمعجم والترتيب والتقسيم | `src/guide/brain/` |
| بناء الجولة ومحركها | `src/guide/tour/` |
| الوعي بالموقف | `src/guide/awareness.ts`، `src/guide/sessionTrail.ts` |
| الواجهة (حزمة كسولة) | `src/components/guide/` |

## إضافة ميزة
1. أضفها في `GUIDE_FEATURES`.
2. أضف جوابها في `GUIDE_BANK`: خطوات فصحى، وصيغ سؤال بالفصحى والكويتية والإنجليزية، و`w` إن كان العنصر مشروطاً بحالة.
3. شغّل `npm run audit:guide-targets`؛ يبلّغ عن أي هدف جولة لا أثر له في الشيفرة.

## قواعد لا تُكسر
- لا طلب شبكي للفهم، ولا مزود ذكاء وقت التشغيل. أُزيل `/api/guide/intent`.
- الجولة لا تختفي صامتة: تظهر العنصر، أو تنتظر فعل المستخدم، أو تقول إنها لم تجده.
- الموقف والتقدم معرّفات وعلامات فقط؛ لا اسم ولا قاعة يُحفظ أو يُرسل.
- الأسئلة بلا جواب تُسجَّل عبر قياس `guide` المجهول أصلاً، وتُطمس فيها كل كلمة خارج مفردات البرنامج، وتظهر للمدير الرئيسي في «المزيد».
- نصوص الواجهة فصحى؛ العامية في `q` والمعجم للفهم فقط.
